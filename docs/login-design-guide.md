# DompetKu Login Design Guide

## Visual Direction
- Style: modern, trustworthy, and calm
- Theme: soft green palette with neutral surfaces
- Goal: make authentication feel safe, clear, and approachable

## Color Palette
- Primary Deep Green: #18372b
- Primary Soft Green: #2f6b49
- Accent Green: #74b67c
- Surface: #f7fcf8
- Neutral Text: #6d7a72
- Error: #b13b4f

## Typography
- Font family: Inter
- Title: 28-32px, semibold
- Subtitle: 14-16px, regular
- Form labels: 13-14px, semibold
- Body text: 13-14px, medium

## Component States
- Input default: soft border, light surface, rounded corners
- Input focus: green border, subtle glow, white background
- Input error: rose border and error message
- Button default: green gradient, pill shape, shadow
- Button hover: slight lift and stronger shadow
- Button active: subtle scale down
- Link default: green text
- Link hover: underline and darker green

## Interaction Flow
1. User enters email and submits
2. OTP is sent and the card switches to OTP verification step
3. User enters 6-digit code and verifies login
4. Success feedback is shown and the user is redirected to dashboard

## Notes
- Maintain generous white space around the card
- Preserve accessible contrast for readability
- Keep transitions short and smooth for a polished feel
